# AI 工作台自定义模型

工作台模型选择器包含“平台模型”和“自定义模型”。用户在“模型配置”保存的启用模型，无需先创建历史会话或绑定智能体，即可用于自己的工作台。选择器每次打开刷新列表，并提供“配置自定义模型”入口。

- 只返回启用且未删除的平台模型、当前用户自己的模型；模型列表不包含密钥和接口地址。
- Claude Code 仅显示 Anthropic Messages 模型；其他协议的模型配置继续保留，供后续运行时扩展使用。
- 已有会话固定使用原模型，切换模型需要新建会话。
- 自定义模型调用保存的模型名称、接口地址和密钥，不进入平台模型的算点预占流程。
- 专家智能体保留原有模型绑定限制。
- 每次 Claude 执行读取最新模型配置，新模型可通过模型列表刷新使用。

本次不新增数据库字段。验证包含 SQLite 权限与列表测试、模拟运行配置测试、前端分组与刷新测试、构建及真实组件的浏览器交互；未调用真实模型供应商。
