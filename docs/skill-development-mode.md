# 技能作者开发模式

技能市场的技能详情中，作者可以开启调试模式，运行时使用 `latest` 工作区文件。默认助手和自定义智能体均可展示、安装作者本人尚未发布过版本的技能：安装后自动开启调试模式，无需先发布版本。之后迭代只需保存技能工作区文件。

- 设置按安装范围保存，仅作者本人可见、可修改；默认助手与各自定义智能体可独立选择工作区或发布版本。
- 每轮运行开始时重新读取已保存的工作区文件，包含脚本及二进制资源。生成独立内容快照，运行期间的保存留到下一轮生效。
- 关闭调试模式后恢复原来安装的发布版本，没有原版本时使用最新发布版本；尚无发布版本时不能关闭调试模式。工作区版本仅供作者本人使用，其他用户及公开 Agent 的访客只能使用发布版本。
- 文件查看支持选择「latest · 工作区最新文件」或历史发布版本；发布包下载仍对应所选发布版本。
- 工作区缺失、为空或包含符号链接时拒绝运行，不自动回退到旧版本。已撤销或已卸载的技能不会因开发模式恢复使用。
- 运行记录使用 `source=workspace`、`version=latest`、`release_id=null` 和内容 SHA-256 区分工作区快照与发布版本。

上线前执行 `backend/migrations/060_skill_development_mode.sql`。升级入口已包含此迁移；如果此前迁移均已完成，可在仓库根目录执行：

```sh
backend/.venv/bin/python backend/migrations/run_upgrade.py --from 060 --apply
```

本次开发不会自动对配置的数据库执行迁移。迁移完成后重启后端并更新前端构建。
